# Readers — SQL Database

A simple library database project created with MySQL.

## Database structure

The database contains three tables:

* `readers` information about library readers
* `books` information about books
* `books_in_use` information about issued books and return dates

## What is included

* Database and table creation
* Primary and foreign keys
* Auto-incrementing IDs
* Sample reader and book data
* Book issue and return records
* Default values and constraints
* Fine calculation based on the return period
* Basic data selection and modification
